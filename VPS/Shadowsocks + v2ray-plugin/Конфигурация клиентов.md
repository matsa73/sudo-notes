### `Shadowrocket` (iOS)
Создать новое подключение:
1. Type: `Shadowsocks`
2. Address: `server_ip`
3. Port: `443`
4. Password: 
5. Method: `chacha20-ietf-poly1305`
6. Plugin: `v2ray-plugin`
    - Mode: `websocket`
    - Host: **[bing.com](https://bing.com/) 
    - Path: `/search`
    - TCP Fast Open: On ❓
    - Muxing: Off
7. TCP Fast Open: On ❓
8. UDP Realy -> UDP Over TCP -> 1
### `V2Box` (Android/iOS)
Добавьте новое подключение (+ -> Add manual config -> `shadowsocks`):
1. Address: `server_ip`
2. Port: `443`
3. Password: 
4. Method: `chacha20-ietf-poly1305`
5. Network: `ws`
6. TLS: `none`
7. Request Host: **[bing.com](https://bing.com/) 
8. Path ServerName: /search

⚠️ Есть несовмесимость `Mux` в `v2ray-plugin` на сервере и в `V2Box`. Поэтому на сервере `Mux` отключён. Но в `V2Box` можно в настройках самого приложения включить `Mux`:
- `mux_concurrency` = 4 или 8
- `xudpProxyUDP443` = allow
