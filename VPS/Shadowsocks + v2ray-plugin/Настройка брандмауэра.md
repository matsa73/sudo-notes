# Настройка брандмауэра

1. Установка и включение `ufw` - это удобная надстройка над `iptables`, которая позволяет управлять сетевыми соединениями с помощью простых и понятных команд

    ```bash
    # Установка
    sudo apt install ufw -y

    # Проверка статуса ufw
    sudo ufw status

    # ⚠️ Разрешение SSH (нужно для входа по SSH-ключу, т.к. вход по паролю отключён)
    sudo ufw allow OpenSSH

    # Включение ufw
    sudo ufw enable
    ```

2. Разрешение порта `443`

    ```bash
    sudo ufw allow 443/tcp
    sudo ufw reload

    # Проверка
    sudo ufw status verbose
    # 443/tcp ALLOW IN Anywhere
    # OpenSSH ALLOW IN Anywhere
    ```

    Для удаления правила используется команда:

    ```bash
    sudo ufw delete allow 443/tcp
    ```

3. Проверка работоспособности

   - На сервере:

    ```bash
    # Проверка статуса сервиса
    sudo systemctl status shadowsocks-libev # active (running)

    # Проверка открытых портов
    sudo ss -tlnp | grep 443 # LISTEN *:443

    # Проверка логов
    sudo journalctl -u shadowsocks-libev -n 20 --no-pager
    ```

   - С локального компьютера:

    ```bash
    Test-NetConnection -ComputerName server_ip -Port 443
    # Должно быть: TcpTestSucceeded : True
    ```
