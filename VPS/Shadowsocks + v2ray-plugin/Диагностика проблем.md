# Диагностика проблем

## Проблема: Сервис не запускается

```bash
# Проверка логов
sudo journalctl -u shadowsocks-libev -n 50 --no-pager

# Проверка конфига
cat /etc/shadowsocks-libev/config.json

# Запуск вручную в debug-режиме
sudo /usr/bin/ss-server -c /etc/shadowsocks-libev/config.json -v
```

## Проблема: Порт 443 закрыт

```bash
# Проверка правил брандмауэра
sudo ufw status verbose

# Удалить правило брандмауэра
sudo ufw delete allow 443/tcp

# Проверка слушает ли процесс порт
sudo ss -tlnp | grep 443

# Проверка прав на порт
sudo sysctl net.ipv4.ip_unprivileged_port_start
```

## 📌 Полезные команды

### Управление сервисом `shadowsocks-libev`

```bash
sudo systemctl status shadowsocks-libev  # статус
sudo systemctl restart shadowsocks-libev # перезапуск
sudo systemctl stop shadowsocks-libev    # остановка
sudo systemctl start shadowsocks-libev   # запуск

# Запуск вручную в debug-режиме
sudo /usr/bin/ss-server -c /etc/shadowsocks-libev/config.json -v
```

### Просмотр логов

```bash
sudo journalctl -u shadowsocks-libev -f                      # реальном времени
sudo journalctl -u shadowsocks-libev -n 50                     последние 50 строк
sudo journalctl -u shadowsocks-libev --since "5 minutes ago" # за 5 минут
```

### Сетевые проверки

```bash
# На сервере
sudo ss -tlnp | grep 443
sudo lsof -i :443

# На клиенте (PowerShell)
Test-NetConnection server_ip -Port 443
```
