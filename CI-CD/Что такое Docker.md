Docker - это инструмент, по сути обычная программа, которая упрощает процесс разработки, запуска и распространения ПО.

# Какие проблемы решает Docker?
Допустим разрабатывается приложение по генерации изображений. Оно может состоять из web-сервера, web-клиента, сервиса генерации изображений, сервиса обработки изображений и множества других систем

DockerEngine - клиент-серверное приложение
	- сервер, создающий образы, контейнеры, тома и управляющий ими
	- api для взаимодействия с сервером
	- инстурмент командной строки (cli) для взаимодействия с сервером через Api

С чем работает Docker?
1. DockerFile - инструкции как создать Docker-Image
2. Docker-Image - шаблон, на основании которого создаются и запускаются контейнеры, которые представляют собой из себя набор файлов, директорий, символический ссылок и необходимых инструментов 
3. Docker-Container - приложение, построенное на основе Docker-Image, с которой исполняются в закрытой файловой системе со своим пространством процессов
