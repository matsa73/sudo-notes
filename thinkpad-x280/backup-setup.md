# Бэкап системы

## Установка

```bash
sudo apt install timeshift
```

## ⚙️ Настройка

1. **Snapshot Type:** `Rsync`. Это стандартный и наиболее совместимый вариант для файловой системы `Ext4`, которая используется в Lubuntu по умолчанию.
2. **Users** - для каждого пользователя есть 3 варианта:
   - `Exclude All` - исключить всё;
   - `Include Hidden` - включить только скрытые файлы;
   - `Include All` - включить всё.
3. **Filters** - включающие и исключающие правила для конкретных папок или файлов:

    ```text
    + /home/username/scripts/**
    /home/username/Videos/**
    /home/username/Music/***
    ```

    Синтаксис окончаний путей:

    | Запись | Что означает                                     |
    | ------ | ------------------------------------------------ |
    | `/**`  | всё содержимое папки; сама папка остаётся пустой |
    | `/***` | и сама папка, и всё её содержимое                |

    Правила в списке применяются сверху вниз. Если включающее правило относится к пути внутри исключённой папки, нужны две вещи:
    - в конце пути `/***`, иначе сама папка попадёт под общее исключение, и `Rsync` не станет заходить внутрь;
    - отдельное правило для каждой родительской папки (со слэшем на конце), например `+ /home/username/.config/`.

## Выбор сценария

| Сценарий         | Вкладка Users | Что попадёт в снимок                           | Когда выбрать                                                      |
| ---------------- | ------------- | ---------------------------------------------- | ------------------------------------------------------------------ |
| A. Белый список  | Exclude All   | только системные файлы и то, что явно включено | нужен минимальный снимок                                           |
| B. Чёрный список | Include All   | всё, кроме явно исключённых папок              | нужны скрытые конфиги и прочее содержимое home, кроме личных папок |

Совет: официальная документация `Timeshift` рекомендует включать хотя бы скрытые файлы (**Include Hidden**), чтобы сохранялись настройки приложений. Необходимо учитывать, что среди скрытых папок бывают очень тяжёлые (`~/.cache`, `~/.nuget`, `~/.ollama` и т. п.).

### Сценарий B: Include All + исключающие правила

1. **Users:** `Include All` для своего пользователя (и для `root`, если нужно).
2. **Filters:** `Add Folders` → добавить исключаемые папки. Они добавятся как исключающие («−»).

В итоге список должен выглядеть так:

```text
   /home/username/Desktop/**
   /home/username/Documents/**
   /home/username/Downloads/**
   /home/username/Music/**
   /home/username/Pictures/**
   /home/username/Public/**
   /home/username/Templates/**
   /home/username/Videos/**
   /home/username/.cache/**
   /home/username/.nuget/**
   + /home/username/**
   + /root/**
```

Все исключающие правила должны стоять **выше** `+ /home/username/**`. Если новые правила оказались ниже, то необходимо сделать так: на вкладке **Users** выбрать **Exclude All**, затем снова **Include All**. `Timeshift` сам перенесёт включающее правило в конец списка. Затем нажать **OK**. Если нужно, добавьте исключения для тяжёлых скрытых каталогов и нестандартных личных папок. Они тоже должны стоять выше включающих правил:

```text
/home/username/.cache/**
/home/username/.nuget/**
```

## Проверка результата

Создайте тестовый снимок и посмотрите, что в него попало. Работать нужно через `sudo`: файлы в снимке сохраняют исходные права.

```bash
sudo timeshift --create --comments "test filters" --tags D
sudo timeshift --list
sudo ls -la /timeshift/snapshots/
```

Команда `--list` покажет, где лежат снимки. Если они на отдельном диске, путь будет другим (обычно `/media/<user>/<UUID>/timeshift/snapshots/`). Подставьте имя снимка из списка:

```bash
sudo ls -la /timeshift/snapshots/<имя_снимка>/localhost/home/username/
sudo du -sh /timeshift/snapshots/<имя_снимка>/localhost/home/username/*
```

Ожидаемый результат:

- Исключённые папки (Documents, Downloads и т. д.) пустые или отсутствуют.
- Нужные скрытые файлы и папки на месте (сценарий B) или есть только включённые вами пути (сценарий A).
- Если в снимке оказалось лишнее или не оказалось нужного, значит, порядок правил или настройка на вкладке **Users** конфликтует с фильтрами.
