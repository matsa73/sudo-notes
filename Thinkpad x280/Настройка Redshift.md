**Redshift** — это программа для автоматической регулировки цветовой температуры экрана. Без ручной настройки при старте программы происходит вот такая ошибка:

Fatal Error: Redshift has terminated unexpectedly with exit code 1: Trying location provider `geoclue2`... Could not connect to wayland display, exiting. Failed to start adjustment method waland. Trying next method... Waiting for initial location to become available... poll: Interrupted system call Unable to get location from provider.

Способ устранения ошибки — ручная конфигурация.
### Ручная конфигурация
1. Создайте конфигурационный файл для Redshift:
```bash
nano ~/.config/redshift.conf
```

```ini
[redshift]
; --- БАЗОВЫЕ НАСТРОЙКИ ---
; Ручное указание координат (обходит geoclue2)
location-provider=manual

; Использовать XF86VidMode протокол через X-сервер (исключит мерцание сразу при старте системы)
adjustment-method=vidmode

; --- ЦВЕТОВАЯ ТЕМПЕРАТУРА (в Кельвинах) ---
temp-day=6500   ; Дневная температура (нейтральный белый)
temp-night=3500 ; Ночная температура (теплый желтый/оранжевый)

; Чем выше значение днём — тем холоднее цвет (6500 - стандарт)
; Чем ниже значение ночью — тем теплее цвет (3500-4500 комфортно для глаз)
; Минимум 1000K (красный), максимум 10000K (синий)

; --- ПЛАВНОСТЬ ПЕРЕХОДА ---
fade=1  ; Плавность переключения между днём и ночью (в секундах)
		; 0 - резкое переключение, 1-100 - плавное

; --- НАСТРОЙКИ ЯРКОСТИ (опционально, необязательные параметры) ---
; brightness-day=1.0    ; Яркость днём (1.0 = 100%)
; brightness-night=0.8  ; Яркость ночью (0.8 = 80%)

; --- ГАММА (опционально, тонкая настройка цветов) ---
; gamma-day=1.0:1.0:1.0      ; R:G:B днём
; gamma-night=0.8:0.8:1.0    ; Ночью можно чуть снизить красный/зеленый

[manual]
; === КООРДИНАТЫ ===
; Указать свои координаты (широта и долгота в градусах)
lat=55.751244    ; Широта (для Москвы)
lon=37.618423    ; Долгота (для Москвы)

; ЗАДАТЬ СВОЙ РАССВЕТ/ЗАКАТ (вручную)
; dawn-time=6:30   ; Время рассвета (начало дневного режима)
; dusk-time=20:30   ; Время заката (начало ночного режима)
```

После добавления конфигурации системный процесс `redshift-qt` подхватит конфиг `~/.config/redshift.conf`. Для этого его необходимо перезапустить:
```bash
killall redshift redshift-qt
ps aux | grep redshift # убедитесь, что не запущено ни одного процесса redshift
```

Из меню пуск заного запустить программу или перезагрузить ПК.
