### 1. ZRAM

Это, пожалуй, **самое эффективное улучшение** для ноутбуков с 8 ГБ ОП на Ubuntu 24.04. Оно позволяет сжимать данные в оперативной памяти, эффективно увеличивая её объем без потери скорости.
- **Почему это важно:** Ubuntu 24.04 не включает ZRAM или ZSWAP по умолчанию [](https://forums.kicksecure.com/t/enable-and-use-zram-instead-for-swap/654/8). Без этой настройки система при нехватке ОП начинает использовать медленный файл подкачки на SSD, что вызывает заметные тормоза.
- **Как это работает:** ZRAM создает сжатый раздел в самой ОП. Данные сжимаются в реальном времени (примерно в 3 раза), что позволяет хранить в 8 ГБ ОП информацию, эквивалентную ~24 ГБ, почти без потери производительности.

Самый простой и надежный способ для Ubuntu — использовать `systemd-zram-generator`.

1. Установите генератор:
```bash
sudo apt install systemd-zram-generator
```
2. Создайте файл конфигурации:
```bash
sudo nano /etc/systemd/zram-generator.conf
```
3. Вставьте в него следующие строки:
```ini
[zram0]
zram-size = ram / 2
compression-algorithm = zstd
swap-priority = 100
```
- `zram-size = ram / 2`: Выделит под ZRAM 4 ГБ (половину от ваших 8). Этого достаточно.
- `compression-algorithm = zstd`: Лучший баланс между степенью сжатия и скоростью для вашего процессора.

4. Сохраните файл (`Ctrl+O`, `Enter`) и закройте (`Ctrl+X`).
5. Перезагрузите ноутбук.

После перезагрузки проверьте, что ZRAM работает, командой `zramctl`. Вы увидите активное устройство `/dev/zram0`.

### 2. Настройка Firefox для экономии ОП

Вы уже поставили "родной" Firefox, минуя Snap. Теперь давайте его "причешем":
1. Откройте `about:config` в адресной строке Firefox.
2. Найдите параметр `dom.ipc.processCount` и установите его в 4.
    - _Что это дает:_ Ограничивает количество процессов для вкладок. Вместо 8 отдельных процессов Firefox будет использовать 4, что ощутимо снизит потребление ОП, особенно если у вас открыто много вкладок.
3. Найдите параметр `browser.sessionhistory.max_total_viewers` и установите его в **0**.
    - _Что это дает:_ Отключает кэширование страниц для кнопок "назад/вперед", освобождая память.
4. Установите расширение `uBlock Origin`. Оно не только блокирует рекламу, но и не позволяет загружаться тяжелым скриптам, экономя ОП и трафик.
