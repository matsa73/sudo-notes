### Уменьшение уровня усиления микрофона

В настройках `Pulse Audio Volume Control` выбрать вкладку `Input Devices` и отрегулировать усиление на уровень на **30-40%**. Уровень "волны" при разговоре должен прыгать где-то в районе 70-80% от максимума, но **никогда не упираться в правый край**.
### Настройка частоты дискретизации микрофона

Хрипы и искажения часто возникают, если микрофон работает на одной частоте (например, 48000 Гц), а система пытается записать на 44100 Гц без качественной конвертации.

1. Узнать имя звукового устройства ввода (микрофона):
```bash
pactl list sources short
```
Нужна строчка, похожая на `alsa_input.pci-...` или `alsa_input.usb-...`

2. Посмотреть текущие параметры этого устройства:  
```bash
pactl list sources | grep -A 10 "Name: имя_источника"
```

В строчке `Sample Specification` будет написано что-то вроде `s16le 2ch 44100Hz` или `48000Hz`.

3. Нужно заставить систему использовать единую частоту. Для этого необходимо создать или отредактировать файл конфигурации `PipeWire`:
```bash
sudo nano /etc/pipewire/pipewire.conf.d/99-custom.conf
```

Если папки `pipewire.conf.d` нет, то нужно создать её: `sudo mkdir -p /etc/pipewire/pipewire.conf.d`

4. Вставить в файл следующий текст, который зафиксирует частоту 48000 Гц (рекомендуется для видео):
```
properties
    context.properties = {
        default.clock.rate = 48000
        default.clock.allowed-rates = [ 48000 44100 32000 ]
}
```

5. Сохранить файл и перезапустить `PipeWire`:
```bash
systemctl --user restart pipewire pipewire-pulse
```
