### Базовая конфигурация TLP

Сначала сделаем резервную копию оригинального конфига:
```bash
sudo cp /etc/tlp.conf /etc/tlp.conf.backup
```

Теперь отредактируем конфиг:
```bash
sudo nano /etc/tlp.conf
```
### Настройки по умолчанию
Раскомментируйте или добавьте следующие параметры (находите строки и убираете # в начале или добавляете, если их нет):
```bash
# ------------------------------------------------------------------------------
# ОПТИМАЛЬНЫЕ НАСТРОЙКИ TLP ДЛЯ Lenovo ThinkPad X280
# ------------------------------------------------------------------------------

# ------------------------------------------------------------------------------
# БАТАРЕЯ (ThinkPad-specific, через acpi-call)
# ------------------------------------------------------------------------------
# 60-90% - идеальный баланс между защитой и удобством
# Если нужно временно зарядить до 100%: sudo tlp fullcharge
START_CHARGE_THRESH_BAT0=60
STOP_CHARGE_THRESH_BAT0=80

# ------------------------------------------------------------------------------
# ЗАЩИТА КЛАВИАТУРЫ (Fn-клавиши)
# ------------------------------------------------------------------------------
USB_AUTOSUSPEND=1
USB_BLACKLIST_PHDEV=1        # 1 = НЕ отключать внутреннюю клавиатуру/тачпад
USB_BLACKLIST_BTUSB=0        # 0 = разрешить отключение Bluetooth (экономия)

# ------------------------------------------------------------------------------
# ПРОЦЕССОР (максимум производительности от сети, экономия от батареи)
# ------------------------------------------------------------------------------
CPU_SCALING_GOVERNOR_ON_AC=performance
CPU_SCALING_GOVERNOR_ON_BAT=powersave
CPU_ENERGY_PERF_POLICY_ON_AC=balance_performance
CPU_ENERGY_PERF_POLICY_ON_BAT=balance_power

# Ограничение частоты на батарее (продлевает время работы)
CPU_MAX_PERF_ON_BAT=70
CPU_BOOST_ON_BAT=0            # Отключить турбо-буст на батарее

# ------------------------------------------------------------------------------
# ПАМЯТЬ И ДИСКИ
# ------------------------------------------------------------------------------
# Оптимальный режим для SSD (экономия + безопасность)
SATA_LINKPWR_ON_BAT="med_power_with_dipm"

# ------------------------------------------------------------------------------
# РАДИО-МОДУЛИ (автоотключение для экономии)
# ------------------------------------------------------------------------------
# Выключать Wi-Fi при подключении Ethernet (удобно для док-станции)
DEVICES_TO_DISABLE_ON_LAN_CONNECT="wifi wwan"
DEVICES_TO_DISABLE_ON_WIFI_CONNECT="wwan"
DEVICES_TO_DISABLE_ON_WWAN_CONNECT="wifi"

# ------------------------------------------------------------------------------
# ПРОЧИЕ ОПТИМИЗАЦИИ (безопасные настройки по умолчанию) - ??????
# ------------------------------------------------------------------------------
# Агрессивное энергосбережение PCIe на батарее
# PCIE_ASPM_ON_BAT=powersupersave

# Звуковая карта - выключать когда не используется
# SOUND_POWER_SAVE_ON_AC=0
# SOUND_POWER_SAVE_ON_BAT=1
```
### Применение настроек TLP

После сохранения файла перезапустите TLP:
```bash
sudo tlp start
sudo systemctl restart tlp

sudo systemctl status tlp # Проверить что TLP работает
```
