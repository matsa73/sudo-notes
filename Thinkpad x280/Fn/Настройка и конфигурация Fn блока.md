## Общий список `Fn` клавиш:

1. **F1**: выключение или включение звука динамиков
2. **F2**: уменьшение громкости динамиков.
3. **F3**: увеличение громкости динамиков.
4. **F4**: выключение или включение звука микрофонов.
5. **F5**: уменьшение яркости экрана компьютера.
6. **F6**: увеличение яркости экрана компьютера.
7. **F7:** управление внешними дисплеями.
8. **F8:** включение или выключение встроенных функций беспроводной связи.
9. **F9:** открытие окна «Настройка»
10. **F10**: включение или выключение встроенных функций Bluetooth.
11. **F11**: открытие страницы настройки клавиатуры.
12. **F12:** вызов определенной функции.
13. **PrtSc**: открытие инструмента «Ножницы».
14. **FnLock:** Переключение режима `FnLock` (активные F-клавиши или спецфункции).
### Шаг 1. Установка необходимых пакетов

```bash
sudo apt install -y acpid acpi pulseaudio-utils libnotify-bin xdotool brightnessctl
```
* `acpid` — демон, отслеживающий ACPI-события от аппаратного обеспечения (нажатие кнопок и тп)
- `acpi` — утилита для диагностики и отображения информации в командной строке
- `pulseaudio-utils` - набор вспомогательных утилит для работы со звуковой системой `PulseAudio`
- `libnotify-bin` - утилиты для отправки системных уведомлений через протокол `Desktop Notifications`
- `xdotool` - утилита для автоматизации действий с окнами в `X11`
- `brightnessctl` - утилита для управления яркостью подсветки экрана и клавиатуры
### Шаг 2. Добавление пользователя в нужные группы (!)

Это необходимо для корректного доступа к устройствам ввода и видео (яркость экрана):
```bash
sudo usermod -aG input,video $USER
```

**Важно:** После этого шага нужно перелогиниться (выйти и зайти снова) или перезагрузиться.
### Шаг 3. Добавить папку для пользовательских скриптов

```bash
sudo mkdir -p ~/.local/bin
sudo mkdir -p ~/.local/bin/fn
```
### Шаг 4. Добавить папку пользовательских скриптов в переменную окружения `PATH`:

- Открыть файл:  `nano ~/.bashrc`
- Добавить в конец файла строку: `export PATH="$HOME/.local/bin:$PATH"`
- Сохранить файл и выполнить в терминале: `source ~/.bashrc`

### Проблемы:
F4: не работает (+ не горит диод) - OK
F5/F6: маленький шаг увеличения/уменьшения яркости экрана (+ нет уведомлений)
F7: не работает
F8: нет уведомлений - OK
F9: не работает - OK
F10: нет уведомлений - OK
F11: назначить - открыть keyboard and mouse settings (через acpi вызвать скрипт, т.к. shortcut не определяется для этой комбинации Fn)
F12: назначить открытие браузера
