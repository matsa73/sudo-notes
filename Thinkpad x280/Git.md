### 1. Установка Git

```bash
sudo apt update && sudo apt install git
git --version # проверка версии
```
### 2. Первичная настройка

Перед началом работы нужно представиться системе, чтобы все изменения (коммиты) были подписаны.
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

Это отключает экранирование "непривычных" байтов в путях, и git начнёт показывать кириллицу как есть. Иначе пути с кириллицей (и вообще любыми не-ASCII символами) отображаются в виде экранированных восьмеричных кодов "\320\277\321\200\320\270\320\262\320\265\321\202.txt" вместо `привет.txt`
```bash
git config --global core.quotepath false
```

Эти данные будут использоваться по умолчанию для всех проектов.
### 3. Локальная работа без сервера

1. Создать папку для проекта и перейти в нее:
```bash
mkdir ~/project/my-first-local-project
cd ~/project/my-first-local-project
```

2. Инициализация в этой папке Git-репозиторий. Это создаст скрытую папку `.git` со всей историей версий:
```bash
git init
```

3. Создать файл, например, `README.md`, и добавить в него какой-нибудь текст.
4. Проверить статус — Git увидит новый неотслеживаемый файл:
```bash
git status
```

5. Добавить файл под версионный контроль и сделайте первый «снимок» состояния (коммит):
```bash
git add README.md
git commit -m "Первый коммит: добавил README"
```

### 4. Основной цикл работы

1. Добавление изменений для следующего коммита:
```bash
git add . # точка означает "все измененные файлы"
```

2. Коммит с комментарием:
```bash
git commit -m "Описание того, что было сделано"
```

### 5. Просмотр изменений

Лучший выбор для просмотра различий - `Meld`

1. Установка:
```bash
sudo apt install meld
```

2. **Настройка как основного инструмента**: Чтобы Git всегда использовал Meld по команде `git difftool`:
```bash
# указание тулы для просмотра изменений
git config --global diff.tool meld
git config --global difftool.prompt false

# указание тулы для мержа изменений
git config --global merge.tool meld
git config --global mergetool.prompt false
```

3. Как использовать?
- **Просмотр правок перед коммитом**: Просто выполнить в папке  проекта `meld .`. Эта команда покажет все изменённые файлы, что позволит в два клика открыть любой из них для детального просмотра.
- **Разрешение конфликтов мержа**: `git mergetool -t meld`
