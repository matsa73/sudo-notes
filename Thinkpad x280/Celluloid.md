# Celluloid

```bash
sudo apt install celluloid ubuntu-restricted-extras
```

`ubuntu-restricted-extras` - это метапакет, который тянет за собой набор кодеков, шрифтов и Flash Player, отсутствующих в системе.

**Celluloid** - это графическая оболочка (фронтенд) к мощнейшему консольному плееру MPV.
**Audacious*** - аудиоплеер, максимально легкий, похож на Winamp. Есть два режима: простой и "скиновый".

Настройка аппаратного декодирования в Celluloid на Lubuntu 24.04 выполняется через файл конфигурации `mpv`. Такой подход надежнее, чем настройка через графический интерфейс, так как позволяет избежать некоторых ошибок.

## Шаг 1. Настройка MPV для аппаратного декодирования

1. Создать папку для настроек `mpv` в домашней директории:

```bash
mkdir -p ~/.config/mpv
sudo nano ~/.config/mpv/mpv.conf
```

2. Добавить содержимое:

```text
# Видеовыход через GPU
vo=gpu

# Включение аппаратного декодирования
hwdec=vaapi-safe

# Высококачественный профиль рендеринга
profile=gpu-hq

# Лучше масштабирование видео (чётче)
scale=ewa_lanczossharp
cscale=ewa_lanczossharp

# Синхронизация с частотой обновления экрана для плавности
video-sync=display-resample 
interpolation
tscale=oversample # Убрать шлейфы при интерполяции

# Использовать X11 EGL вместо устаревшего GLX (обязательно для modesetting + Picom)
gpu-context=x11egl
```

`video-sync=display-resample` — она обеспечивает плавность видео за счет точной синхронизации с частотой обновления экрана
`hwdec=vaapi-safe` — золотая середина: пробует `vaapi`, но fallback к программному декодированию при ошибке

## Шаг 2. Указание Celluloid использовать файл конфигурации `mpv`

1. Откройте **Celluloid**.
2. Перейдите в меню (значок гамбургера) -> **Preferences** (Ctrl + ,).
3. Переключитесь на вкладку **Config Files**.
4. Установите галочку **Load mpv configuration file** и укажите путь к вашему файлу `~/.config/mpv/mpv.conf`

## Шаг 3. Проверка работы

Перезапустите Celluloid и откройте любое видео (например, в формате H.264 или H.265). Убедиться, что ускорение работает, можно двумя способами:

* **Через терминал:** Запустите Celluloid из терминала (`celluloid`), откройте видео и посмотрите на вывод текста. Должна появиться строка, указывающая на используемый метод `hwdec` (например, `Using hardware decoding (vaapi)`).
* **Через интерфейс:** Во время воспроизведения нажмите `Ctrl + H`. В появившемся окошке с информацией о видео найдите строку "HW Decoder". Если там написано что-то отличное от "no", значит, все настроено верно.

Загрузку GPU можно проверить, запустив тулу `intel_gpu_top` и видео в высоком разрешении. Посмотрите на график `Video` в утилите. Если значение в столбце `Video` поднимается выше нуля (например, 5-20%), **GPU успешно занимается аппаратным декодированием видео**. Если же активность идет только по строке `Render/3D` или `Video`
остается на нуле, то декодирование идет на CPU.
