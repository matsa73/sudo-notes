Сама по себе `LXImageQt` поддерживает только базовые форматы. Однако в её документации и описании прямо указано, что для добавления поддержки HEIC, RAW, WEBP и других форматов достаточно установить дополнительные пакеты.

**Что нужно установить:**
1. **`qt5-image-formats-plugins`** — добавляет поддержку WEBP, TIFF и др.
2. **`kimageformat-plugins`** — ключевой плагин для HEIC/HEIF, PCX, XCF и множества RAW-форматов

После установки `LXImageQt` сможет открывать практически любые современные форматы изображений. Установка проста и делается одной командой:

```bash
sudo apt install qt5-image-formats-plugins kimageformat-plugins
```
