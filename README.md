### 3. Связывание заметок

В отличие от папок, связи важнее иерархии. Делайте ссылки на другие заметки:

```markdown
## Установка Shadowsocks

Перед установкой убедитесь, что настроен [ssh-key](ссылка/на/файл)  на VPS.

После установки проверьте [firewall-rules](ссылка/на/файл) — порт 8388 должен быть открыт.

Если ничего не работает — смотри [vpn-troubleshooting](ссылка/на/файл).
```

Даже если заметки лежат в разных папках, ссылки их свяжут. Через год у вас получится паутина знаний, а не просто список файлов.

### 4. ✍️ Основы Markdown для заметок

Вот минимум, который нужен в 90% случаев. Этого достаточно.

**Заголовки:**

```markdown
# Самый большой заголовок (один на файл)
## Заголовок второго уровня
### Заголовок третьего уровня
```

**Выделение текста:**

```markdown
*курсив* или _курсив_
**жирный** или __жирный__
~~зачёркнутый~~
`моноширинный` (для команд, имён, кода)
```

**Списки:**

```markdown
1. Первый пункт нумерованного списка
2. Второй пункт
⋅⋅*Ненумерованный вложенный список.
1. Сами числа не имеют значения, лишь бы это были цифры
⋅⋅1. Нумерованный вложенный список
4. И еще один пункт.

⋅⋅⋅Внутри пунктов списка можно вставить абзацы с таким же отступом. Обратите внимание на пустую строку выше и на пробелы в начале (нужен по меньшей мере один, но здесь мы добавили три, чтобы также выровнять необработанный Markdown).

⋅⋅⋅Чтобы вставить разрыв строки, но не начинать новый параграф, нужно добавить два пробела перед новой строкой.⋅⋅
⋅⋅⋅Этот текст начинается с новой строки, но находится в том же абзаце.⋅⋅
⋅⋅⋅(В некоторых обработчиках, например на Github, пробелы в начале новой строки не нужны.)

* Ненумерованный список можно размечать звездочками
- Или минусами
+ Или плюсами
```

**Ссылки и изображения:**

```markdown
[текст ссылки](https://example.com)
[ссылка на другую заметку](250515-ssh-setup.md)
![подпись](assets/images/screenshot.png)
```

**Код с подсветкой:**

```bash
sudo apt update
sudo apt install docker.io
```

```sql
SELECT * FROM users WHERE id = 1;
```

**Цитаты и важные вставки:**

```markdown
> Важное предупреждение: не забудьте сделать бэкап!

> [!NOTE]
> Полезное примечание

> [!WARNING]
> Осторожно: эта команда удаляет все данные!
```

**Чеклисты (для гайдов):**

```markdown
- [x] Настроить SSH-ключ
- [ ] Установить Docker
- [ ] Настроить брандмауэр
```

**Таблицы:**

```markdown
| Команда | Описание |
|---------|----------|
| `ls -la` | Показать все файлы |
| `df -h` | Свободное место на дисках |
```

**Горизонтальная линия (для разделения):**

```markdown
---
```

### 5. Настройка VS Code

Установите расширения (Ctrl+Shift+X):

- `yzhang.markdown-all-in-one` — форматирование, оглавления
- `bierner.markdown-mermaid` — диаграммы
- `Draw.io Integration` - интеграция с draw.io
- `streetsidesoftware.code-spell-checker` — проверка орфографии
- `streetsidesoftware.code-spell-checker-russian` - проверка орфографии (русский)
- `DavidAnson.vscode-markdownlint` - статический анализатор  
- `goessner.mdmath` - математические формулы

Как быстро найти заметку?

1. Через поиск в VS Code: Ctrl+Shift+F
2. Через INDEX.md: создайте файл INDEX.md в корне и вручную или скриптом поддерживайте алфавитный указатель
3. Через git grep (если помните слово):

```bash
git grep -n "shadowsocks"
```
