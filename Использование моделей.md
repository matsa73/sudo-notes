# Матрица выбора моделей (Для пользователя и Агента)

Используйте эту таблицу для выбора оптимальной модели через OpenRouter/Web в зависимости от задачи, балансируя стоимость токенов и качество рассуждений:

| Категория задачи | Рекомендуемая модель | Где запускать | Ключевое преимущество | Стратегия экономии токенов |
| :--- | :--- | :--- | :--- | :--- |
| **Теория и концепции** | `anthropic/claude-3.5-sonnet` | 🌐 Web UI (Бесплатно) | Лучшая структура текста, понятные объяснения, отличные саммари. | Используйте Web-версию, чтобы беречь баланс OpenRouter для кода. |
| **Сложный дебаг и логи** | `deepseek/deepseek-r1` | 💻 VS Code (OpenRouter) | Глубокие рассуждения. Находит первопричину скрытых ошибок. Очень дешевая. | Включайте сразу, если команда Linux или скрипт падают с непонятной ошибкой. |
| **Сложный код и IaC** | `anthropic/claude-3.5-sonnet` | 💻 VS Code (OpenRouter) | Максимальная точность для Dockerfile, конфигов Nginx и сложных Bash-скриптов. | Используйте инкрементальные промпты (правки по месту), чтобы не переписывать файлы целиком. |
| **Рутина и автодополнение** | `qwen/qwen-2.5-coder-32b` | 💻 VS Code (OpenRouter) | Ничтожная стоимость (центы), высокая скорость, хороша для простых команд Linux. | Держите активной для базовой проверки синтаксиса и генерации шаблонного кода. |
| **Большие доки и книги** | `google/gemini-2.5-pro` / `flash` | 💻 VS Code (OpenRouter) | Гигантское окно контекста. Поддержка кэширования для повторных вопросов. | Загружайте учебник или лог целиком один раз; задавайте все вопросы внутри одной сессии. |


💡 Краткое правило для работы (Алгоритм):Нужно понять концепцию или почитать теорию? 👉 Идите в веб-Claude.Упала непонятная ошибка в терминале Linux? 👉 Включайте DeepSeek-R1 в VS Code.Нужно написать сложный Docker-манифест или скрипт? 👉 Включайте Claude 3.5 в VS Code.Пишете рутинный код или базовую команду? 👉 Переключайтесь на Qwen 2.5 Coder.Нужно скормить ИИ целый учебник? 👉 Включайте Gemini.Хотите, я добавлю эту таблицу прямо в ваш файл agent.md в раздел документации, чтобы она всегда была перед глазами у вас и у самого агента?
